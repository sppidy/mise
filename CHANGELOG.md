This file records user-visible changes to Mise. The project follows [Semantic Versioning](https://semver.org/).

No changes yet.

## [0.1.0] - 2026-09-04

First public release.

- Added the self-hosted web app, JSON persistence API, Docker image, and native Android client.
- Added recipe imports from Schema.org pages, shared text, social captions, photos, PDFs, DOCX files, Markdown, plain text, and CSV files.
- Added local-first storage, server sync, favorites, collections, grocery lists, cook mode, serving controls, and themes.
- Added guarded outbound fetching, bounded downloads, pinned DNS resolution, cached cover images, and optional local Ollama fraction correction.
- Added the AGPL license, Android ML Kit linking exception, dependency notices, privacy policy, security policy, and contributor documentation.
